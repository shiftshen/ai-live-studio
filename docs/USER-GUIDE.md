# AI Live Studio 一键开播使用教程

## 开播前

1. 打开飞鹅打印机，确认纸张充足。
2. 连接 Brio 100 或 iPhone 摄像头，把镜头对准打印机出纸口。
3. 登录抖音直播伴侣；TikTok 测试时使用可开播的 TikTok 账号。

## 一键启动

双击 `/Volumes/M2USB/Projects/ai-live-studio/一键启动直播工具.command`。启动工具会检查后台、抖音采集、飞鹅打印机和摄像头，并自动绑定当前抖音房间。四项均显示正常后再点击直播伴侣的“开始直播”。

也可在终端运行：

```sh
cd /Volumes/M2USB/Projects/ai-live-studio
npm run live:start
```

## 直播伴侣素材顺序

1. 底层只放真实摄像头 `Brio 100`，选择“平铺缩放”铺满竖屏。
2. 顶层放透明图片 `/Volumes/M2USB/Projects/ai-live-studio/public/live-assets/camera-rewards-zh.png`。
3. 不要采集手机桌面或直播伴侣窗口，避免把设置按钮播出去。
4. 摄像头画面应从透明区域完整透出，左侧只保留简洁奖励说明。

## 默认中文互动

- 进场：播报欢迎、显示昵称，并打印欢迎小票。
- 关注：播报感谢、显示关注提示，并打印感谢小票。
- 评论“你好”：中文语音问候、画面提示和小票。
- 评论“祝福”或“生日快乐”：生成短祝福并语音播报。
- 点赞累计 10、50、100：更新数字并分档播报；100 次可打印纪念小票。
- 任意礼物、小心心或礼物累计 10、66：按本次连送最终数量只触发最高档，播报昵称、礼物和数量，并打印对应小票。

TikTok 房间使用同一流程，互动文案和语音自动切换为泰文。

## 直播中检查

打开 `http://127.0.0.1:8890` 查看房间连接、真实事件、语音、打印队列和失败原因。只有 `live` 来源的真实事件会触发实体打印；模拟和重放默认不会出纸。飞鹅“平台受理”只表示平台收到任务，实体出纸仍以摄像头和现场纸张为准。

## 关播

先在抖音或 TikTok 官方直播工具中结束直播，再运行：

```sh
cd /Volumes/M2USB/Projects/ai-live-studio
npm run down
```

异常打印不会盲目重投；需要补打时在后台填写原因并使用“补打”。
